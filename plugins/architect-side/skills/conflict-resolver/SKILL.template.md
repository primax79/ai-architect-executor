# {{NAME}}

Use this skill to resolve merge conflicts in files generated by parallel
{{BLOCK:audience}}Executor tasks (delegated work dispatched in parallel worktrees that then
need merging back together){{/BLOCK}}.

## Logic and Behavior

{{BLOCK:body}}- **Context:** you have been invoked by the Architect to resolve merge
  conflicts (`<<<<<<< HEAD`).
- **Action:** find every file with conflict markers in the current working
  directory. Analyze both versions of the code logically.
- **Resolution:** edit the files, removing the markers and integrating the
  code so that the semantics of both parallel features are preserved.
- **Verification:** run the linter and/or a basic build to confirm the
  resolution did not break the syntax.{{/BLOCK}}
